# 封面 SOP（Thumbnail）

> 状态：初版。每次迭代有结论时，由 daily-optimizer 提 PR 修订。

## 目标

封面和标题是同一枚硬币的两面：标题负责"悬念冻结"，封面负责"一眼看懂冲突"。
3 秒内观众必须能回答：这是谁、发生了什么、我想知道然后呢。

## 硬规则

1. **文字 ≤ 6 个词**，全部大写或首词大写，字号占封面高度 ≥ 25%。
2. **人物主体占画面 ≥ 40%**：欧美女性面孔（情绪：震惊/冷笑/落泪三选一），Mafia 语境配西装男性剪影或豪宅/豪车背景。
3. **配色**：墨黑底 + 象牙白字 + 金/绯红点缀（和正片视觉系统一致）。
4. **不剧透结局**：封面只能呈现标题前半句的冲突，不许出现反转结果。
5. **和标题互补不重复**：标题说了台词，封面就给画面；标题给了悬念，封面就给情绪。

## 评审清单（thumbnail-reviewer 用）

- [ ] 3 秒测试：遮住标题，能说出冲突吗？
- [ ] 手机小图测试：缩到 120px 宽，字还认得清吗？
- [ ] 情绪测试：女主表情和故事核心情绪一致吗？
- [ ] 同质化测试：和本频道近 5 支封面放一起，能一眼区分吗？
- [ ] 标题互补测试：没有重复标题里的词超过 2 个吗？

## 数据迭代

- 每支视频记录：CTR（如果有）、播放量、点赞率。
- 封面类型打标签：`人物特写` / `双人对峙` / `场景` / `文字主导`。
- daily-optimizer 每周统计各标签的平均播放，胜出标签写入"当前主推版式"。
