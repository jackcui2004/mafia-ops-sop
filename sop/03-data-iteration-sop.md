# 数据迭代 SOP

> 每天 08:00（美东）由 daily-optimizer 执行。只用公开数据。

## 数据采集（data-analyst）

1. 对每个频道，打开主页，按最新排序取近 24h 发布/有明显数据变化的视频。
2. 记录：视频链接、标题、封面（截图或描述）、播放量、点赞数、评论数、发布时间。
3. 写入 `data/daily/YYYY-MM-DD.md`，一人一段。
4. 没人提交数据时，Agent 自己去看（DECISIONS.md 已定）。

## 基线

- 每个频道维护 7 天滚动平均播放（`channels/<name>/profile.md` 里更新）。
- 单支视频播放 > 2× 基线 → 标记 `爆款`；< 0.5× 基线 → 标记 `哑火`。

## 迭代分析（daily-optimizer）

1. **找规律**：爆款的共同点（标题结构？封面类型？选题关键词？发布时间？）。
2. **找反例**：哑火的共同点。
3. **出补丁**：结论必须可执行，例如"题型 A 标题近 7 天平均播放高 40%，下支优先用题型 A"。
4. **改 SOP**：结论稳定出现 3 次以上 → 提 PR 修订 `sop/` 对应文档。
5. **写报告**：`reports/YYYY-MM-DD.md`，包含：数据表、发现、补丁、需要人拍板的事（如果有）。

## 批奏折

推给人的只有：SOP 规则变更、选题方向大改、对外发布。
其他（标题微调、封面版式、下支选题建议）Agent 直接写进报告，不打扰。
